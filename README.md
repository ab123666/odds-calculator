# odds-calculator

多选项赔率分配计算器（Dutching / 竞彩对冲）：**给定各选项赔率，按目标净利润反推最小投入与每注金额；或给定总投入求最大保底利润；同时判定这组赔率里有没有套利空间**。投注额一律按 2 元步进（竞彩单注 2 元）。

[在线使用](https://ab123666.github.io/odds-calculator/)

## 特性

- **两种模式**：目标净利润 → 最小投入（`findMinCost`）；总投入 → 最大净利润（`findMaxWin`）。
- **2 元步进**：`calcMinEvenBet` 求「使 `bet × odds ≥ 毛返奖`」的最小偶数，带浮点容差（`eps ≤ 0.5`）和上下双向收敛，避免 `ceil` 因精度把投注额多进 2 元。
- **综合赔率**：`1 / Σ(1/o_i)`，即覆盖全部结果后的理论赔率。
- **套利判定**：`calcDiff = 1 − Σ(1/o_i)`，`≤ 0` 时顶部直接提示「无套利空间」并停止计算。
- **回本赔率**：第二组赔率（另一玩法或另一平台）用第一组的总投入当目标利润，反推出覆盖所需的投入；最终净利润会把这份回本投入扣掉，同时给出「合计投入」与「基本投入」两个数字。
- **理论值起步 + 搜索兜底**：先用闭式解算理论最小投入，再从 `⌈S*⌉` 起按 2 递增找第一个可行解，兼顾速度与 2 元取整。
- **输入防护**：只接受数字和一个小数点、赔率强制 ≥ 1、上限 `9.99999999e8`、输入框禁用滚轮改值。
- **实时重算**：任何输入变动立即重算；目标净利润的 ± 步进会直接跳到「下一个真正改变总投入」的值，而不是机械 +1。

## 快速开始

```bash
git clone https://github.com/ab123666/odds-calculator.git
cd odds-calculator
python -m http.server 8000
```

打开 <http://localhost:8000>，或直接双击 `index.html`。

## 使用

1. 选 Tab：「目标净利润」或「总投入」。
2. 填各选项赔率：`+ 添加` 增项、`−` 删项，至少保留一项。
3. 目标净利润模式下可再填一组「回本赔率」，用于把主投注的成本赚回来。
4. 看结果表：每项投注额、总投入、最小 / 最大净利润；有回本方案时额外显示扣除后的净收益。

## 数学说明

设赔率 `o₁ … oₙ`，令 `d = 1 − Σ(1/oᵢ)`（只有 `d > 0` 才有解，即综合赔率 > 1）：

- 综合赔率：`O = 1 / (1 − d) = 1 / Σ(1/oᵢ)`
- 目标净利润 `W` 的理论最小投入：`S* = W · (1 − d) / d`
- 预算 `B` 的最大理论净利润：`W* = B · d / (1 − d)`
- 实际结果按 2 元取整后贴着理论值走，误差来自取整，不来自公式

反过来说：`d ≤ 0` 意味着无论怎么分配，必有一路亏钱 —— 这就是「无套利空间」的判据。

## 已知限制

- 只适用于「必有一项命中」的互斥结果集；走水、退款、部分结算不建模。
- 2 元步进让结果必然略微偏离连续最优（每项最多差 2 元）。
- 搜索上限 `MAX_SEARCH_S = 1e15`，超大目标会返回空结果。
- 不保存历史，刷新即清空。
- 计算全在前端完成，不联网取任何实时赔率。
